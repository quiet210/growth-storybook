# 나의 성장 그림책 도우미

중학교 국어 「멍키 스패너」 단원(문학과 성장) 6차시 **AI 그림책 만들기** 활동을 돕는 웹앱입니다.
AI·디지털 기반 연구학교 연구수업용으로 만들었습니다.

- **학생**: 5차시 활동지 내용 정리 → Gemini 스토리북 프롬프트 자동 완성(개인정보 자동 점검) → 그림책 점검 → 친구 이야기·정리
- **교사**: 수업방 만들기, 학생 접속 QR, 실시간 진행 현황, 성장 문장 모아보기(TV용), CSV 내려받기

## 구조

```
화면 (이 저장소, GitHub Pages)  ──►  데이터 서버 (Google Apps Script)  ──►  구글 시트
 index.html   학생용                    apps-script/Code.gs                 '수업방' 시트
 teacher.html 교사용                                                         '학생기록' 시트
```

- 학생 기록은 **설치한 선생님의 구글 시트에만** 저장됩니다. GitHub에는 화면 코드만 올라갑니다.
- 여러 선생님이 하나의 서버를 함께 씁니다. 선생님마다 **수업방**을 만들고, 학생은 수업방 코드(또는 QR)로 들어옵니다. 수업방끼리는 기록이 섞이지 않습니다.
- 학생은 **수업방 + 반 + 번호 + 이름**으로 구분합니다. 같은 반·번호라도 이름이 다르면 다른 학생으로 저장합니다.

## 설치 (관리자 선생님 1명이 한 번만)

### 1. 데이터 서버 만들기 (Apps Script)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. (예: `성장 그림책 데이터`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. `Code.gs` 내용을 모두 지우고 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)를 붙여넣습니다.
4. 맨 위 `SCHOOL_CODE: 'change-me'`를 **우리 학교 선생님들만 아는 코드**로 바꿉니다.
   선생님들이 수업방을 만들 때 이 코드가 필요합니다.
5. 저장한 뒤, 위쪽 함수 선택에서 `setup`을 고르고 **실행**합니다. 권한 승인 창이 뜨면 허용합니다.
   (시트에 '수업방', '학생기록' 탭이 생깁니다.)
6. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** ← 꼭 이것으로 (구글 로그인 없이 학생이 접속해야 함)
7. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 2. 화면 연결 (GitHub)

1. 이 저장소의 [`config.js`](config.js)를 열고 연필(편집) 버튼을 누릅니다.
2. `API_URL`의 `PASTE_YOUR_APPS_SCRIPT_URL_HERE`를 1-7에서 복사한 주소로 바꾸고 **Commit changes**를 누릅니다.
3. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 `https://<깃허브아이디>.github.io/growth-storybook/` 에서 열립니다.

| 누가 | 주소 |
|---|---|
| 학생 | `https://<아이디>.github.io/growth-storybook/` (수업방 QR로 들어오면 코드 입력 생략) |
| 교사 | `https://<아이디>.github.io/growth-storybook/teacher.html` |

### Code.gs를 고친 뒤에는

Apps Script에서 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 이렇게 해야 주소가 바뀌지 않습니다.
('새 배포'를 누르면 주소가 바뀌어서 `config.js`도 고쳐야 합니다.)

## 함께 쓰는 선생님용 안내

1. 교사 주소(`…/teacher.html`)에 들어가 **새 수업방 만들기**를 누릅니다.
2. 학교 코드, 이름, 학년, 수업하는 반(예: `5, 8, 15, 18`), 패들렛 주소, 비밀번호를 넣습니다.
3. 나오는 **수업방 코드 6자리와 비밀번호를 메모**합니다.
4. 수업 시간에 **학생 접속 QR·링크**를 TV에 띄웁니다.
5. 다음부터는 **내 수업방 들어가기**에서 코드와 비밀번호로 들어갑니다.

### 수업 운영 팁
- 태블릿을 여러 학생이 돌려 쓸 때는 끝난 학생이 **다른 학생으로 시작**을 누르게 해 주세요.
- 현황판에 **⚠ 번호 중복**이 보이면 한 학생이 이름을 다르게 쓴 경우가 많습니다. 행을 눌러 잘못된 기록을 지우면 됩니다.
- **성장 문장 모아보기**를 TV에 띄우면 정리 단계의 "문학은 나에게 ___을 가능하게 해 준다"를 함께 볼 수 있습니다. 익명을 고른 학생은 이름이 가려집니다.

## 다른 학교에서 쓰려면

이 저장소를 **Fork**한 뒤 위의 설치 1~2단계를 그대로 하면 됩니다. 학생 기록은 각 학교 선생님의 구글 시트에 따로 저장됩니다.

## 개인정보

- 학생 이름·반·번호는 선생님 구글 시트에만 저장되고, AI(Gemini)에 보내는 프롬프트에는 들어가지 않습니다.
- 프롬프트 화면에서 전화번호·주소·동호수·본인 이름이 보이면 복사를 막고, 학교 이름·친구 이름처럼 보이는 표현에는 경고를 띄웁니다. 자동 점검은 보조 수단이므로 학생이 직접 확인하도록 지도해 주세요.
- 교사 비밀번호는 암호화(SHA-256)되어 저장됩니다.
- 학년도가 끝나면 시트의 '학생기록'을 지우거나 시트 파일을 정리해 주세요.
